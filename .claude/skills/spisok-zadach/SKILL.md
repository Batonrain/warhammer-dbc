# Список задач

Эта команда уже один раз была выполнена неправильно (03.09.2026) — вместо
темы задачи сгруппировали по приоритету P1/P2/P3 через `bd ready`, хотя
точное правило для этой команды уже лежало в bd-памяти. Чтобы это не
повторялось, при срабатывании этого скилла — **первым действием, до всего
остального** — прочитать сохранённое правило:

```bash
bd recall cmd-spisok-zadach
```

Дальше выполнять ровно то, что там написано: какие задачи брать (статус,
непустое описание), как фильтровать, по каким темам группировать (готовая
таксономия), как держать вместе эпик с подзадачами, и какие тикеты — служебное
исключение внизу списка вне тем.

Не подменять эту команду дефолтным `bd ready` и не сортировать/не подписывать
разделы по приоритету или по типу задачи (bug/feature/task/chore) — владельцу
проекта это не критерий, важна тема.

Если содержимое правила `cmd-spisok-zadach` устарело или требует правки —
менять через `bd remember "<новый текст>" --key cmd-spisok-zadach`, а не
здесь: этот файл — только гарантия того, что правило прочитано перед ответом,
не дубликат самого правила.
