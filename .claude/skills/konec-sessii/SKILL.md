# Конец сессии

Полный протокол — в bd-памяти, не здесь:

```bash
bd recall cmd-konec-sessii
```

Прочитать его **заново** при каждом запуске, не полагаться на то, что было в
контексте сессии раньше — протокол может обновиться другой сессией между
стартом и концом (уже случалось 10.09.2026, см. историю изменений в самой
заметке и в `bd recall artifact-vedomost`).

Коротко, что там: три этапа — Обзор → Локальный → Удалённый. Гейт на этапе 1
(хвосты/предупреждения — если не чисто, ждать подтверждения пользователя,
дальше идти автоматически). Явный триггер вместо автозапуска (искл. —
`night-session`, см. её же п.8). Публикация «Ведомости рокового похода» —
сама сессия, последним шагом этапа 3, через лок `wdbc-izef` (образец —
`wdbc-a4l`, лок живого тестирования).

Если содержимое `cmd-konec-sessii` устарело или требует правки — менять через

```bash
bd remember "<новый текст>" --key cmd-konec-sessii
```

сохраняя прежний текст целиком и дописывая новое отдельным блоком с датой и
поводом, а не здесь: этот файл — только гарантия того, что протокол
прочитан перед выполнением, не дубликат самого протокола.
