# Кандидаты в скиллы/агенты — перенесено в bd

Этот файл был общим markdown-накопителем находок с ретроспектив конца
сессии. Снят по wdbc-n8i: ручная дозапись строки в общий файл ломается,
если две параллельные сессии допишут его одновременно, не видя строк друг
друга — а именно так копится большинство находок в этом проекте.

Механизм теперь — bd, тег `skill-candidate`: одна тема = один bd-тикет,
повторное появление той же находки — `bd comment` на существующий тикет
(атомарная вставка, не гонка). Правило «в реальный скилл/агент — только на
третьем появлении» и точные команды — `bd recall skill-candidate-protocol`.

Накопленные до переноса ~33 находки (2026-08-31…2026-09-08) заведены в bd
тем же тегом — `bd list --label skill-candidate`.
