# Документация Warhammer DBC

Служебные документы для разработки системы. Игровых правил здесь нет, они живут в
компендиумах и в книгах.

| Документ | Что внутри | Когда читать |
|---|---|---|
| [architecture-plan.md](architecture-plan.md) | Пошаговый план архитектурных исправлений: 7 этапов, у каждого шага критерий готовности | Перед тем как браться за любой этап |
| [rules-format.md](rules-format.md) | Справочник формата правил: предикаты, эффекты, вытеснение | Постоянно на этапах 1–3, потом при добавлении любой расы или книги |

## Коротко о задаче

Правила игры сейчас записаны прозой в поле `benefit`, а поведение раздаётся кодом.
Из-за этого «у эльдар этот талант работает иначе» означает новое ветвление в
[../module/sheets/actor-sheet.mjs](../module/sheets/actor-sheet.mjs) на 7 215 строк, а
не новую запись в данных.

План переводит правила в данные: условие плюс эффект, один конвейер броска, один
реестр источников. После этого добавление расы, ветки или дисциплины перестаёт
затрагивать ядро.

Полный разбор с цифрами и ссылками на строки: аудит от 10 августа 2026.
