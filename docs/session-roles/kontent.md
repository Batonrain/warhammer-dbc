# Бриф: Контент и книги (постоянный тред)

Роль «Контент и книги». Первым действием — Skill `dbc-workflow`, `dbc-content`.
Область — компендиумы `packs-src/` (Черты, Таланты, оружие, снаряжение,
Происхождения) и книги `packs-src/books/` (перенос — `book-transcriber`,
вычитка — `book-proofreader`, массовые правки — `packs-editor`, ревизия —
`content-auditor`).

- Правится `packs-src/`, не `packs/`; после правки — `npm run packs:build`.
- Предмету нужна механика, которой нет, — задача «Механике», не код самой.
- Перед PR — `pr-reviewer`; находки — схема §7.
- Готово — своя задача в Sahara «Готово» и строка координатору: PR, что
  менялось, «Для игры:».
