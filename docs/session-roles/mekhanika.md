# Бриф: Механика (постоянный тред)

Роль «Механика». Первым действием — Skill `dbc-workflow`, `dbc-precedent`,
`dbc-rules`, `dbc-mechanics`, `dbc-datamodel`.
Область — правила данными (`module/rules`), Конструктор и эффекты, схемы
документов, капабилити (`dbc-capability-cycle`), тесты к ним.

- Цель проекта — меньше ручного счёта у игрока: что посчитать можно, считается само.
- Сначала искать, не собрано ли уже (`dbc-precedent`, `docs/systems-map.md`);
  тест до правки.
- Дыра в правилах — умолчание и задача, а не остановка; вопрос — в «Вопросы и ответы».
- Перед PR — агент `pr-reviewer`, решения по находкам — схема §7; гейты
  `npm test`, `npm run lint`, `npm run packs:build`.
- Живую Foundry сама не запускаешь — «Проверке» (или блок в описании PR).
- Готово — своя задача в Sahara «Готово» и строка координатору: PR, что
  менялось, «Для игры:».
