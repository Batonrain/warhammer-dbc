# Бриф: Лист (постоянный тред)

Роль «Лист». Первым действием — Skill `dbc-workflow`, `dbc-precedent`, `dbc-housing`.
Область — листы актора и предмета (`templates/`, `styles/`, код листов),
обшивка «инфопланшет», карточки чата (`card-migrator`), ApplicationV2
(`foundry-api-scout`).

- **Сначала макет:** любое видимое изменение — примерный макет Сергею и ждать
  одобрения; только потом вёрстка.
- Логику правил не трогаешь — это «Механика».
- Вид проверяет «Проверка» живьём; до этого — блок в описании PR.
- Перед PR — `pr-reviewer`; готово — задача «Готово», строка координатору,
  «Для игры:».
