# Ручная сверка шага 5.3: лист персонажа после разбора на модули

Шаг 5.3 [плана](../architecture-plan.md). Расчёт из листа вынесен в модули, тесты
писались до переезда и после него не менялись — совпадение ожиданий и есть
доказательство, что расчёт не сдвинулся. Автоматика закрывает расчёт; здесь
остаётся то, чего заглушка Foundry не видит: показ, привязка обработчиков к
живой разметке и состояние открытого окна.

Проходить на персонаже, у которого есть чем щёлкать: раса с Путями (аэльдари)
или Астартес, психосилы, препараты, оружие с профилями и щит.

## Состояние окна: единственное, чего тесты не видят вовсе

Это не расчёт и в актора не пишется — живёт до закрытия листа. Проверять сменой
вкладки и ре-рендером (правкой любого поля): состояние должно пережить оба.

| № | Что | Проверка |
| --- | --- | --- |
| 44 | прокрутка вкладок | после ре-рендера остаётся на месте |
| 45 | свёртка Стоек и Приёмов (БОЙ) | переживает ре-рендер |
| 46 | свёртка категории Снаряжения | переживает ре-рендер |
| 47 | свёртка улучшений под носителем | переживает ре-рендер |
| 48 | гайд имплантов «▾ Импланты» | переживает ре-рендер |
| 49 | свёртка панели Путей | переживает ре-рендер |
| 50 | тема листа по расе / мировоззрению / классу | меняется вместе с расой |
| 51 | «▸/▾» описания таланта, черты, мутации | открывает строку СВОЮ, а не однофамильцев |
| 52 | зрачок Третьего Глаза | следит за курсором |
| 53 | драг предмета из листа | оружие тащится в «Осквернение» на вкладке Завесы |
