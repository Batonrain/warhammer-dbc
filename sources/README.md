# sources/

Единственный источник оригиналов книг правил, с которыми идёт сверка
(`tools/book-coverage.py`, `tools/book-pdf-diff.py`, агенты `book-proofreader`
и `book-transcriber`) — решение владельца, 09.09.2026.

Кладите сюда САМЫЕ ПОСЛЕДНИЕ версии файлов, заменой поверх старых. Старые
копии, которые могли раньше лежать в других папках на диске (например
`D:\tRPG\Warhammer\Самоделки` или `~/Downloads`) — больше не источник
истины, даже если ещё существуют физически.

Сами файлы книг в git не попадают (`.gitignore`) — это купленный/авторский
контент, не для публикации. Только этот README остаётся под версионным
контролем, чтобы папка и её назначение не терялись.

## Формат

Предпочтительный — **Markdown** (экспорт Google Docs, «Файл → Скачать →
Markdown (.md)»): `tools/book-coverage.py::src_md` читает его штатно, и
09.09.2026 проверено глазами на самой сложной таблице всей книги
(статблок существа с характеристиками) — передаёт не хуже HTML/ZIP,
никакой новой каши markdown-экспорт не вносит (см. wdbc-xsxy).

**PDF надёжен ТОЛЬКО для документов, которые больше не редактируются**
(пример — `DoomBC_Core .pdf`, `DoomBC_S_Chaos.pdf`, `DoomBC_Machines.pdf`:
содержимое не меняется, разница форматов роли не играет). Для документов,
которые ещё правятся, PDF — источник ложных находок: текстовый слой может
отставать от актуальной редакции гугл-дока (см. находку 09.09.2026,
wdbc-xsxy — поиск по PDF не нашёл 4 существ, которых автор добавил уже
ПОСЛЕ того, как этот PDF был выгружен).

Если для документа нужна ещё и постраничная визуальная сверка
(`tools/book-pdf-diff.py` — работает только по PDF, для .md/.zip/.docx
отказывается сознательно), докладывайте рядом ещё и PDF-версию как
вторичный, необязательный файл.

Какое имя файла отвечает какому паку (`packs-src/books/<slug>.json`) —
смотрите `tools/book-coverage.py::SOURCES`, не подбирайте по похожести имён.
