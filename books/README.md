# books/

Единственный источник оригиналов книг правил, с которыми идёт сверка
(`tools/book-coverage.py`, `tools/book-pdf-diff.py`, агенты `book-proofreader`
и `book-transcriber`) — решение владельца, 09.09.2026.

Кладите сюда САМЫЕ ПОСЛЕДНИЕ версии файлов. Старые копии, которые могли
раньше лежать в других папках на диске (например `D:\tRPG\Warhammer\
Самоделки` или `~/Downloads`) — больше не источник истины, даже если ещё
существуют физически.

Сами файлы книг в git не попадают (`.gitignore`) — это купленный контент,
не для публикации. Только этот README остаётся под версионным контролем,
чтобы папка и её назначение не терялись.

## Формат

Предпочтительный — **ZIP** (экспорт Google Docs, «Веб-страница (HTML,
ZIP-архив)»): надёжный текстовый слой, без каши от двухколоночной вёрстки,
которой страдает PDF. `tools/book-coverage.py` читает его штатно.

Если нужна ещё и постраничная визуальная сверка (`tools/book-pdf-diff.py` —
только он работает по PDF, для ZIP/DOCX отказывается сознательно), докладывайте
рядом ещё и **PDF**-версию того же документа — это вторичный, необязательный
файл.

Какое имя файла отвечает какому паку (`packs-src/books/<slug>.json`) —
смотрите `tools/book-coverage.py::SOURCES`, не подбирайте по похожести имён.
